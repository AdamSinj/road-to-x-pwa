ROAD TO X PWA V4 — MISE À JOUR GITHUB

1. Décompresse cette archive.
2. Envoie le CONTENU du dossier à la racine du dépôt GitHub road-to-x-pwa (pas le dossier lui-même).
3. Remplace index.html, app.js, style.css, sw.js, manifest.json et le dossier icons.
4. Valide avec Commit changes. GitHub Pages publie automatiquement la branche main / root.
5. Sur iPhone, ouvre l’adresse du site dans Safari et actualise. Si l’ancienne version persiste, supprime les données du site adamsinj.github.io dans Réglages > Safari > Avancé > Données de sites, puis rouvre le site.

SYNCHRONISATION
- Reconnecte-toi une fois dans les paramètres avec le même compte Supabase que sur PC. La V4 renouvelle ensuite automatiquement la session.
- Pour recevoir les données du PC : bouton « Récupérer les données PC → iPhone ».
- Pour envoyer les changements de l’iPhone : bouton « Envoyer les données iPhone vers le cloud ».
- Ne clique pas sur l’envoi si le PC contient la copie de référence.
- La connexion seule ne remplace et n’envoie plus aucune donnée.

Les données locales ne sont pas incluses dans cette archive.
